# 体系效能指标（kpi-metrics）

> ⚠️ **本文件为通用方法论 + 样例推断，正式口径待业务确认。**
> 数据来源：`output/$(CASE).evt`（事件记录）、`output/$(CASE).aer`（回放）、`output/$(CASE).log`（日志）。
>
> **注意**：本文件只用于**设计工程时预留指标口径**（如配置好事件输出项）；指标计算发生在仿真之后，不在 afsim-forge-skill 日常流程内。

---

## 1. 指标分层

| 层 | 指标 | 说明 |
| :-- | :-- | :-- |
| **感知层** | 首次探测距离、探测概率、虚警率、航迹建立时间 | 传感器效能 |
| **跟踪层** | 航迹连续性、跟踪精度、航迹交接成功率 | 航迹质量 |
| **指挥层** | 决策时延、任务下发成功率、指挥链生存率 | C2 效能 |
| **交战层** | 发射成功率、命中率、单发毁伤概率 | 火力效能 |
| **体系层** | **杀伤链闭合率**、**闭合时间**、体系生存率、任务完成率 | 综合效能 |

---

## 2. 关键指标定义

| 指标 | 定义 | 数据来源 |
| :-- | :-- | :-- |
| **首次探测距离** | 首次 `SENSOR_TRACK_INITIATED` 时目标到传感器的距离 | `.evt` |
| **探测概率 Pd** | 进入探测范围的目标中被发现的比例 | `.evt` |
| **虚警率** | 虚警数 / 总探测数 | `.evt` |
| **航迹建立时间** | 从首次探测到航迹稳定的耗时 | `.evt` |
| **航迹连续性** | `SENSOR_TRACK_UPDATED` 的连续覆盖率 | `.evt` |
| **决策时延** | 从航迹可用到任务下发的时间 | `.evt` + 任务日志 |
| **发射成功率** | `WEAPON_FIRED` / 任务下发数 | `.evt` |
| **命中率** | `WEAPON_HIT` / `WEAPON_FIRED` | `.evt` |
| **杀伤链闭合率** | 完成 探测→跟踪→决策→交战→命中 的目标数 / 来袭目标数 | `.evt` |
| **杀伤链闭合时间** | `WEAPON_HIT` 时间 − 首次探测时间 | `.evt` |
| **体系生存率** | 未被 `PLATFORM_BROKEN` 的己方平台数 / 初始数 | `.evt` |
| **任务完成率** | 完成的任务数 / 下发的任务数 | 任务日志 |

---

## 3. 关键事件对照表

| 事件 | 对应指标 |
| :-- | :-- |
| `PLATFORM_INITIALIZED` | 体系初始状态（分母） |
| `SENSOR_TRACK_INITIATED` | 首次探测距离、探测概率 |
| `SENSOR_TRACK_UPDATED` | 航迹连续性 |
| `WEAPON_FIRED` | 发射成功率 |
| `WEAPON_HIT` | 命中率、杀伤链闭合 |
| `WEAPON_MISSED` | 脱靶 |
| `PLATFORM_BROKEN` | 体系生存率、毁伤效果 |

---

## 4. 事件输出配置建议

为支撑上述指标，生成工程时**按需开启事件**：

```text
event_output
   file output/$(CASE).evt
   enable PLATFORM_INITIALIZED
   enable PLATFORM_BROKEN
   enable WEAPON_FIRED
   enable WEAPON_HIT
   enable WEAPON_MISSED
   enable SENSOR_TRACK_INITIATED
   enable SENSOR_TRACK_UPDATED
end_event_output
```

| 配置 | 适用 |
| :-- | :-- |
| `enable all` | 快速起步 / 全面分析（`.evt` 体积大） |
| 逐项 `enable` | 面向特定指标的轻量分析 |

> **注意**：`.evt` 体积可观（样例 367,417 行）。指标分析建议**逐项开启**。

## 5. 分析工作流（供设计参考，非本 skill 职责）

```
仿真运行（由其他工具执行）
   ↓
output/$(CASE).evt（事件记录）
   ↓ 解析
按时间线提取关键事件 → 计算指标
   ↓
输出体系效能报告
```

> **afsim-forge-skill 的职责边界**：只负责**生成工程时预留好事件输出配置**，使后续指标分析可行。
> **不做指标计算**（仿真与取结果仅在交付后按用户要求进行）。
